# pipeline/template/

Boilerplate files that `build_reel.py` copies into every generated HyperFrames project (so a project works standalone).

| File | Role |
|---|---|
| `hyperframes.json` | HyperFrames project config (asset and component paths, media auto-proxy) |
| `meta.json` | Project metadata |
| `package.json` | Marks the project as an ES-module package |

Do not edit these for visual changes; the look is generated by `../build_reel.py`.
